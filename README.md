<h1 align="center">📱 Sports App (iOS Swift)</h1>

---

A modern iOS Sports App built using **Swift**, consuming **AllSports API**, supporting **Dark/Light mode, onboarding, favorites, and league tracking**.

---

## 👨‍💻 Team Members
- Ahmed Mohamed  
- Emad Ayed  

---

## 🚀 Tech Stack

- Swift (UIKit)
- Alamofire
- CoreData
- UserDefaults
- SDWebImage
- Lottie-ios
- SwiftTheme
- SkeletonView
- SwiftUI-Shimmer

---

## ✨ App Features

| Feature | Description |
|--------|-------------|
| ⚽ Sports | CollectionView (2 items per row) showing sports |
| 🏆 Leagues | TableView with circular badges |
| 📊 League Details | Upcoming + latest events + teams |
| ⭐ Favorites | Stored using CoreData |
| 👥 Team Details | Clean UI with team info |
